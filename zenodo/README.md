# Zenodo

This directory supports Zenodo publication preparation for Jounes-Chougui-Research.

## Purpose

Use this folder to organize metadata, DOI planning notes, release checklists, and archival documentation for public research deposits.

## Expected Contents

- Zenodo metadata drafts
- DOI planning notes
- Release checklists
- Version descriptions
- Links to archived records

## Guidelines

Zenodo materials should be suitable for public release and should not contain secrets, credentials, private algorithms, API keys, restricted datasets, or security-sensitive mechanisms.
