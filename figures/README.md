# Figures

This directory is reserved for public figures, diagrams, plots, and visual research assets.

## Purpose

Use this folder to store publication-supporting visual materials that help explain experiments, architecture, datasets, and analysis results.

## Expected Contents

- Diagrams
- Plots
- Architecture illustrations
- Measurement visualizations
- Publication-ready image assets

## Guidelines

Figures should avoid exposing sensitive system internals, private algorithms, credentials, or restricted operational information. Include source notes or captions when appropriate.
