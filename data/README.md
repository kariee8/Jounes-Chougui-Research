# Data

This directory is reserved for public dataset descriptions, metadata, and data-use documentation.

## Purpose

Use this folder to describe datasets that support research reports or publications. When raw data is included, it should be reviewed for public release and accompanied by clear provenance, licensing, and usage notes.

## Expected Contents

- Dataset overview files
- Metadata descriptions
- Data dictionaries
- Public provenance notes
- Links to archived datasets or DOI records

## Guidelines

Do not store secrets, credentials, private datasets, personal information, API keys, restricted logs, or security-sensitive material. If a dataset cannot be safely shared, provide only a public summary and archival plan.
